# 📌 About the Project

Mental-health-related experiences such as **depression, anxiety, stress, emotional distress, loneliness and hopelessness** are increasingly expressed through social-media platforms.

The enormous volume of user-generated textual content creates an opportunity to investigate whether **Natural Language Processing (NLP)** and **Machine Learning (ML)** can identify linguistic patterns associated with different levels of mental-health-related risk.

However, conventional machine-learning systems often provide only a final prediction without explaining the reasoning behind that prediction.
