## 📌 Overview

Mental-health-related experiences such as **depression, anxiety, stress, emotional distress, loneliness, and hopelessness** are increasingly expressed through online platforms.

Social-media text provides a large-scale source of naturally occurring language that can be analysed using **Natural Language Processing (NLP)** and **Machine Learning (ML)**.

However, a major limitation of conventional machine-learning systems is that they often produce only a prediction:
